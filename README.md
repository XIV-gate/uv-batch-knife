# UV Batch Knife

Интерактивный нож для UV Editor, который одним разрезом обрабатывает все
пересечённые UV-грани, включая наложенные друг на друга острова.

UV Batch Knife создаёт настоящую топологию меша: новые вершины и рёбра
появляются не только в UV-развёртке, но и в геометрии объекта. Новые рёбра
можно автоматически помечать швами и раздвигать по UV, чтобы после разреза
Blender воспринимал стороны как отдельные UV-острова.

- Минимальная версия: Blender 5.0.
- Проверено в Blender 5.2 LTS.
- Автор: XIVgate.
- Лицензия: GPL-3.0-or-later.

## Установка и обновление

1. Скачать ZIP на странице
   [GitHub Releases](https://github.com/XIV-gate/uv-batch-knife/releases).
2. Открыть `Edit → Preferences → Extensions`.
3. Открыть меню со стрелкой вниз и выбрать `Install from Disk`.
4. Выбрать ZIP расширения и убедиться, что **UV Batch Knife** включён.

Для обновления установите новый ZIP тем же способом поверх старой версии.
Если в уже открытом Blender осталось старое поведение, выключите и снова
включите расширение либо перезапустите Blender.

## Подготовка

1. Откройте UV Editor.
2. Переведите редактируемый меш в `Edit Mode`.
3. Выделите нужные грани или оставьте их видимыми — точный охват зависит от
   параметра **Target Faces**.
4. Наведите курсор на область UV Editor.

У UV Editor нет отдельного Edit Mode. Режим редактирования включается для
меша, а UV Editor отображает его редактируемые грани.

## Запуск инструмента

Запустить нож можно тремя способами:

- нажать `K`, когда курсор находится над UV Editor;
- выбрать `UV → UV Batch Knife`;
- нажать `N → UV → UV Batch Knife → Start UV Batch Knife`.

После запуска курсор принимает форму ножа. До первого клика показывается
позиция будущей точки с учётом выбранного снапа. При успешной привязке точка
становится зелёной.

## Быстрый разрез

1. Нажмите `K` — сразу включится `C1 Multi-Point`.
2. Поставьте точки кликами ЛКМ.
3. Нажмите `Enter` или `Numpad Enter`.

Для обычного прямого отрезка поставьте только две точки и нажмите `Enter`.
Один и тот же путь будет применён ко всем пересечённым и разрешённым
параметром **Target Faces** UV-граням.

## Полное управление

| Клавиша | Действие | Где работает |
|---|---|---|
| `K` | Запустить UV Batch Knife | UV Editor |
| ЛКМ | Поставить точку или подтвердить форму | Все режимы |
| `C` | Цикл `C1 Multi-Point → C2 Infinite Line → C3 Grid Knife` | Во время работы |
| `S` | Цикл режимов снапа `S0 → S1 → S2 → S3 → S4` | Во время работы |
| `N` | Переключить `N0 NORMAL ↔ N1 DETACH` для отделения целых UV-островов | Во время работы |
| `E` | Переключить `E1 CORNER ↔ E2 EDGE` для внутренних концов пути | Во время работы |
| `Enter` | Выполнить многоточечный разрез | `C1 Multi-Point` |
| `Backspace` | Удалить последнюю точку | `C1 Multi-Point` |
| `Ctrl` | Ближайшая ось для линии или шаг угла 15° для грида | Зависит от режима |
| `X` | Зафиксировать горизонтальное направление | `C1` и `C2` |
| `Y` | Зафиксировать вертикальное направление | `C1` и `C2` |
| Колесо мыши | Изменить число ячеек | `C3 Grid Knife` |
| `Alt` | Округлять сторону грида с шагом 0.1 UV | `C3 Grid Knife` |
| `Esc` или ПКМ | Отменить инструмент | Все режимы |

Повторное нажатие активной клавиши `X` или `Y` снимает фиксацию оси.
Grid Knife больше не переключается клавишей `G`: он является третьим режимом
в цикле `C`.

## Режимы разреза

### C1 Multi-Point

Основной режим, включённый сразу после запуска.

1. Каждый клик ЛКМ добавляет очередную точку ломаной.
2. Точки можно ставить на границах и непосредственно внутри UV-полигонов.
3. `Backspace` удаляет последнюю поставленную точку.
4. `Enter` или `Numpad Enter` создаёт разрез.

`Ctrl` временно направляет текущий сегмент по ближайшей горизонтальной или
вертикальной оси. `X` и `Y` фиксируют соответствующую ось до повторного
нажатия.

Если первая или последняя точка находится внутри UV-полигона, открытый конец
автоматически достраивается до его границы. Способ достроения переключается
клавишей `E` прямо во время работы:

| Режим | Поведение |
|---|---|
| `E1 CORNER` | По умолчанию соединяет внутренний конец с ближайшим видимым углом UV-полигона |
| `E2 EDGE` | Использует кратчайший путь до ближайшей точки на ребре полигона |

При одинаковом расстоянии выбор угла выполняется детерминированно в
UV-пространстве, поэтому наложенные острова получают согласованный результат.
Настройка внутренних концов действует только на `C1 Multi-Point`.

### C2 Infinite Line

Бесконечная прямая, проходящая через две указанные точки.

1. После запуска нажмите `C` один раз.
2. Первый клик ЛКМ задаёт опорную точку.
3. Второй клик задаёт направление и сразу выполняет разрез.

Фактическая линия продолжается в обе стороны за пределы поставленных точек и
режет все пересечённые разрешённые UV-грани. Для точного направления доступны
`Ctrl`, `X` и `Y`.

Параметр **Interior Endpoints** здесь не используется, потому что у
бесконечной прямой нет открытых внутренних концов.

### C3 Grid Knife

Квадратная режущая сетка с одинаковым количеством ячеек по ширине и высоте.

1. После запуска нажмите `C` два раза.
2. Первый клик ЛКМ задаёт центр грида.
3. Двигайте мышь: расстояние от центра меняет размер, а направление задаёт
   поворот и положение одного из углов.
4. Колесом мыши выберите количество подразделений.
5. Второй клик ЛКМ выполняет разрез.

Дополнительное управление:

- `Ctrl` округляет угол поворота с шагом 15°;
- `Alt` округляет полную сторону грида с шагом 0.1 UV;
- `S` переключает снап центра и управляемого угла;
- колесо задаёт от 1 до 64 ячеек по каждой стороне.

Значение размера `1.0 UV` соответствует стороне одного UV-тайла. Грид всегда
остаётся квадратным, его ячейки имеют равную ширину и высоту. Режутся только
грани, попавшие в квадратную область грида.

Рядом с курсором показываются полный размер, размер одной ячейки, угол,
количество подразделений и активный режим снапа. Ещё до первого клика подпись
показывает `C3 Grid Knife`, число ячеек и выбранный режим снапа.

## Режимы снапа

Клавиша `S` циклически переключает пять состояний:

| Режим | Привязка |
|---|---|
| `S0 OFF` | Без привязки |
| `S1 UV Points` | К ближайшим UV-вершинам |
| `S2 UV Grid` | К координатной сетке UV Editor |
| `S3 Edge Centers` | К центрам UV-рёбер |
| `S4 Face Centers` | К центрам UV-полигонов |

Снап работает уже для самой первой точки. Текущий режим отображается рядом с
курсором и в строке состояния.

Рядом с режимом снапа всегда показывается состояние отделения островов:
`N0 NORMAL` сохраняет обычную связанную топологию, а `N1 DETACH` включает
отделение целого UV-острова по его 3D-периметру.

Шаг `S2 UV Grid` берётся из настроек UV Editor:

- **Fixed** — из `Custom Grid Subdivisions`;
- **Pixel** — из разрешения активного изображения;
- **Dynamic** — автоматически подбирается по масштабу UV Editor.

Для `S2` текущий шаг также показывается рядом с курсором.

## Область обработки: Target Faces

| Режим | Какие грани режутся |
|---|---|
| **Visible in UV Editor** | Грани, доступные в текущем UV-контексте |
| **Selected Mesh Faces** | Только выделенные грани меша |

Поведение **Visible in UV Editor** зависит от `UV Sync Selection`:

- при выключенном Sync обрабатываются выделенные грани меша, которые
  отображаются в UV Editor;
- при включённом Sync обрабатываются все нескрытые грани редактируемого меша.

В Blender 5.2 независимые флаги UV-выделения больше не открыты в Python API,
поэтому **Selected Mesh Faces** использует выделение граней самого меша.

## Отделение разрезаемого UV-острова в 3D

Клавиша `N` переключает специальный топологический режим:

| Состояние | Поведение |
|---|---|
| `N0 NORMAL` | Обычный разрез общего mesh-ребра; новая вершина появляется во всех смежных гранях |
| `N1 DETACH` | Перед разрезом отделяет затронутый UV-остров в 3D по его UV-периметру |

`N1 DETACH` нужен, когда разрез UV-края не должен добавлять «зеркальную»
вершину на другой стороне того же mesh-ребра. Такая другая сторона может
принадлежать как соседнему UV-острову, так и другой части той же цельной
развёртки.

### Как определяется периметр

- Если разрез создаёт новую точку на внешнем UV-контуре острова, весь этот
  остров сначала отсоединяется в 3D по своему UV-периметру.
- Периметр определяется по UV-разрывам аналогично `Seams from Islands`.
- UV-разрывное mesh-ребро размыкается даже тогда, когда обе его грани входят
  в один остров через другие UV-непрерывные рёбра. Именно такой случай
  встречается в цельной крестообразной развёртке куба.
- Внутренние грани одного UV-острова остаются сваренными между собой — режим
  не разделяет каждый полигон отдельно.
- UV-непрерывные внутренние рёбра не размыкаются. Если линия пересекает такое
  ребро, общая точка создаётся штатно, потому что она нужна обеим разрезаемым
  граням одного острова.
- Другие UV-позиции разомкнутого mesh-ребра сохраняют исходное число вершин и
  не получают точку от разреза целевого участка.
- Координаты геометрии не сдвигаются и новый Blender Object не создаётся:
  меняется только связность топологии вдоль UV-периметра.
- Если разрез полностью лежит внутри острова и не добавляет точку на его
  внешнем UV-контуре, остров не отсоединяется.

Режим работает с `C1 Multi-Point`, `C2 Infinite Line` и `C3 Grid Knife`.
Состояние сразу отображается у курсора и в строке состояния и сохраняется для
следующего запуска инструмента.

### Detach и Split UV Islands — не одно и то же

| Функция | Что изменяет |
|---|---|
| `N1 DETACH` / **Detach Cut UV Islands** | Размыкает существующий UV-периметр в геометрии перед разрезом, предотвращая лишние точки в других UV-позициях общего mesh-ребра |
| **Split UV Islands** | После разреза слегка раздвигает его стороны только в UV-пространстве, превращая новый разрез в UV-шов |

Эти функции можно использовать одновременно: сначала `N1 DETACH` защищает
остальной контур от лишних вершин, затем **Split UV Islands** разделяет стороны
самого нового разреза в UV.

## Настройки в N-панели

Откройте `N → UV → UV Batch Knife`.

- **Start UV Batch Knife** — запустить оператор без горячей клавиши;
- **Shortcut: K** — напоминание о горячей клавише;
- **Author: XIVgate** — автор расширения;
- **GitHub Repository** — открыть репозиторий;
- **Instructions** — открыть полную инструкцию в README.

Рабочие режимы в N-панели не дублируются: `C`, `S`, `N` и `E`
переключаются непосредственно во время работы инструмента и показывают своё
состояние рядом с курсором и в строке состояния.

## Параметры последней операции

После выполненного разреза нажмите `F9`, чтобы открыть параметры последней
операции.

| Параметр | Назначение |
|---|---|
| **Cut Mode** | Переключить линейный разрез и Grid Knife |
| **Line Mode** | Выбрать Multi-Point или Infinite Line |
| **Target Faces** | Выбрать видимые либо выделенные грани |
| **Interior Endpoints** | Выбрать способ достроения внутренних концов Multi-Point |
| **Grid Size** | Полная сторона квадратного грида в UV-единицах |
| **Grid Angle** | Поворот грида |
| **Grid Subdivisions** | Одинаковое число ячеек по горизонтали и вертикали |
| **Detach Cut UV Islands** | Отсоединить целый UV-остров в 3D, если разрез добавляет точку на его внешнем UV-контуре |
| **Split UV Islands** | Разделять стороны разреза на отдельные UV-острова |
| **Separation** | Величина микросдвига одной стороны в UV-пространстве |
| **Mark New Edges as Seams** | Помечать созданные рёбра UV-швами |

Параметры грида показываются только для Grid Knife, а **Interior Endpoints** —
только для Multi-Point.

## Что создаёт оператор

- настоящие вершины и рёбра меша;
- одинаковый разрез на всех пересечённых наложенных UV-островах;
- UV-швы на новых рёбрах, если включён **Mark New Edges as Seams**;
- отдельные UV-острова после микросдвига, если включён **Split UV Islands**;
- разомкнутый 3D-периметр целевого UV-острова, если включён
  **Detach Cut UV Islands** и разрез пересекает его внешний контур.

Операция поддерживает обычную отмену Blender через `Ctrl+Z`.

## Типовые сценарии

### Разрезать стопку островов одной ломаной

1. Сделайте нужные грани видимыми или выделенными.
2. Нажмите `K`.
3. Поставьте точки пути поверх UV-островов.
4. Нажмите `Enter`.

### Разрезать всё одной бесконечной прямой

1. Нажмите `K`, затем один раз `C`.
2. Поставьте две точки направления.

### Нарезать квадратную область равными ячейками

1. Нажмите `K`, затем два раза `C`.
2. Укажите центр.
3. Настройте размер, угол и количество ячеек.
4. Подтвердите вторым кликом.

### Разрезать край цельной развёртки куба без лишних точек

1. Нажмите `K`.
2. Нажимайте `N`, пока рядом с курсором не появится `N1 DETACH`.
3. Проведите путь через нужный внешний край UV-развёртки.
4. Для `C1 Multi-Point` подтвердите разрез клавишей `Enter`.

Плагин найдёт весь UV-разрывный периметр затронутой развёртки и разомкнёт его
в 3D до создания новых вершин. Поэтому соответствующие рёбра, расположенные в
других местах UV-развёртки, не получат дополнительные точки.

## Ограничения и примечания

- Инструмент работает с мешами в `Edit Mode` и требует активную UV-карту.
- Настройка внутренних концов применяется только к началу и концу
  Multi-Point, но не к промежуточным точкам.
- Совпадение разреза с существующим UV-ребром не создаёт дубликат ребра.
- Поскольку создаётся реальная топология, изменяется сам меш, а не только его
  UV-координаты.
- **Detach Cut UV Islands** намеренно создаёт несваренную топологию вдоль
  UV-периметра затронутого острова; визуально геометрия остаётся на месте.
- На очень больших мешах поиск пересечений может занять несколько секунд.
