# UV Batch Knife

Интерактивный нож для UV Editor в Blender 5.x.

Одна линия в UV-пространстве одновременно режет все пересечённые UV-грани,
включая наложенные друг на друга острова. Оператор создаёт настоящие вершины
и рёбра в меше. По умолчанию новые рёбра помечаются швами, а одна половина
сдвигается на незаметную величину, чтобы Blender воспринимал результат как
два отдельных UV-острова при упаковке.

## Установка

1. Blender → Edit → Preferences → Extensions.
2. Меню со стрелкой вниз → Install from Disk.
3. Выбрать ZIP расширения.

## Использование

1. Открыть UV Editor и перевести меш в режим редактирования.
2. Оставить нужные UV-грани видимыми либо выделить соответствующие грани
   меша.
3. Навести курсор на UV Editor и нажать `K`.
4. Указать начало и конец линии двумя кликами ЛКМ.
5. `Esc` или ПКМ отменяет оператор.

После запуска курсор принимает форму ножа, как у стандартного Knife в
3D Viewport, и автоматически восстанавливается после завершения или отмены.

Во время выбора второй точки:

- удерживать `Ctrl` — привязать линию к ближайшей оси;
- нажать `X` — зафиксировать горизонтальный разрез;
- нажать `Y` — зафиксировать вертикальный разрез;
- повторно нажать выбранную ось — снять фиксацию.

Оператор также доступен через `UV → UV Batch Knife`.
Отдельная кнопка находится в боковой панели UV Editor: `N → UV → UV Batch Knife`.

После разреза параметры доступны в панели последней операции (`F9`):

- **Target Faces** — все видимые в UV Editor грани или только выделенные
  грани меша.
- **Extend Line** — продолжить линию бесконечно в обе стороны.
- **Split UV Islands** — сделать половины отдельными UV-островами.
- **Separation** — микросдвиг одной половины в UV-пространстве.
- **Mark New Edges as Seams** — пометить новые рёбра UV-швами.

Для режима **Visible in UV Editor** при выключенном UV Sync Selection
обрабатываются выбранные в меше грани, то есть те, которые отображаются в
UV Editor. При включённом UV Sync Selection обрабатываются все нескрытые
грани меша.

В Blender 5.2 независимые флаги UV-выделения больше не открыты в Python API,
поэтому вариант **Selected Mesh Faces** использует выделение самого меша.

## Ограничения

- Конечный отрезок должен пересечь границу полигона дважды. По умолчанию
  включено продолжение линии, поэтому это условие обычно выполняется.
- Совпадение линии с уже существующим UV-ребром не создаёт дубликат ребра.
- На очень больших мешах поиск пересечений может занять несколько секунд.
