# UV Batch Knife

Интерактивный нож для UV Editor в Blender 5.x.

Линия или многоточечная ломаная в UV-пространстве одновременно режет все
пересечённые UV-грани,
включая наложенные друг на друга острова. Оператор создаёт настоящие вершины
и рёбра в меше. По умолчанию новые рёбра помечаются швами, а одна половина
сдвигается на незаметную величину, чтобы Blender воспринимал результат как
два отдельных UV-острова при упаковке.

## Установка

1. Blender → Edit → Preferences → Extensions.
2. Меню со стрелкой вниз → Install from Disk.
3. Выбрать ZIP расширения.

## Использование

1. Открыть UV Editor и перевести меш в режим редактирования.
2. Оставить нужные UV-грани видимыми либо выделить соответствующие грани
   меша.
3. Навести курсор на UV Editor и нажать `K`.
4. Указать начало и конец линии двумя кликами ЛКМ либо выбрать
   многоточечный режим и завершить ломаную клавишей `Enter`.
5. `Esc` или ПКМ отменяет оператор.

После запуска курсор принимает форму ножа, как у стандартного Knife в
3D Viewport, и автоматически восстанавливается после завершения или отмены.

До первого клика рядом с курсором показывается будущая точка. Она сразу
учитывает выбранный режим снапа и становится зелёной при успешной привязке.

Во время работы:

- нажимать `S` — циклически переключать режим привязки:
  `S0` без привязки, `S1` UV-вершины, `S2` координатная сетка UV,
  `S3` центры UV-рёбер, `S4` центры UV-полигонов;
- нажимать `C` — циклически переключать конечный отрезок (`C1`),
  бесконечную линию (`C2`) и многоточечный Knife (`C3`);
- нажать `G` — переключить обычную линию и квадратный Grid Knife;
- удерживать `Ctrl` — привязать линию к ближайшей оси;
- нажать `X` — зафиксировать горизонтальный разрез;
- нажать `Y` — зафиксировать вертикальный разрез;
- повторно нажать выбранную ось — снять фиксацию.

Текущий режим `S0`–`S4` показывается рядом с курсором и в строке состояния.
Для `S2` также отображается текущий шаг. В режиме Fixed используется
настройка **Custom Grid Subdivisions** UV Editor, в режиме Pixel — разрешение
активного изображения, а в режиме Dynamic шаг автоматически зависит от
масштаба UV Editor.

### Multi-Point Knife

1. После запуска нажать `C` два раза, чтобы выбрать `C3 Multi-Point`.
2. Каждый клик ЛКМ добавляет очередную точку ломаной. Точки разрешено
   ставить непосредственно внутри UV-полигонов.
3. `Backspace` удаляет последнюю поставленную точку.
4. `Enter` или `Numpad Enter` завершает разрез.

Если первая или последняя точка находится внутри UV-полигона, нож
автоматически соединяет её с ближайшей точкой периметра. Поэтому открытый
конец внутри грани не вызывает ошибку и образует корректный топологический
разрез. На наложенных островах та же ломаная применяется ко всем граням.

### Grid Knife

1. После запуска ножа нажать `G`.
2. Первый клик задаёт центр квадратного грида.
3. Движение мыши одновременно меняет размер и поворот; курсор задаёт один
   из углов квадрата.
4. Колесо мыши меняет одинаковое число ячеек по горизонтали и вертикали.
5. `Ctrl` округляет поворот с шагом 15 градусов.
6. `Alt` округляет общую сторону грида с шагом 0.1 UV. Значение `1.0`
   соответствует стороне одного UV-тайла.
7. Рядом с курсором показываются размер грида, размер одной ячейки, угол и
   количество ячеек.

Грид всегда квадратный, а его ячейки имеют одинаковую ширину и высоту.
Режутся только UV-грани, попавшие внутрь квадратной области.

Оператор также доступен через `UV → UV Batch Knife`.
Отдельная кнопка находится в боковой панели UV Editor: `N → UV → UV Batch Knife`.

После разреза параметры доступны в панели последней операции (`F9`):

- **Target Faces** — все видимые в UV Editor грани или только выделенные
  грани меша.
- **Line Mode** — конечный отрезок, бесконечная линия или многоточечная
  ломаная.
- **Split UV Islands** — сделать половины отдельными UV-островами.
- **Separation** — микросдвиг одной половины в UV-пространстве.
- **Mark New Edges as Seams** — пометить новые рёбра UV-швами.

Для режима **Visible in UV Editor** при выключенном UV Sync Selection
обрабатываются выбранные в меше грани, то есть те, которые отображаются в
UV Editor. При включённом UV Sync Selection обрабатываются все нескрытые
грани меша.

В Blender 5.2 независимые флаги UV-выделения больше не открыты в Python API,
поэтому вариант **Selected Mesh Faces** использует выделение самого меша.

## Ограничения

- Концы конечного отрезка или ломаной внутри грани автоматически
  достраиваются до ближайшего участка её периметра.
- Совпадение линии с уже существующим UV-ребром не создаёт дубликат ребра.
- На очень больших мешах поиск пересечений может занять несколько секунд.
